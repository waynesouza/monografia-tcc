\begin{resumo}
A modelagem de bancos de dados é uma etapa fundamental no desenvolvimento de sistemas de \textit{software}, e os diagramas ER constituem uma ferramenta essencial para essa finalidade. No entanto, as soluções disponíveis no mercado dificilmente combinam colaboração em tempo real, modelagem interativa e acesso gratuito em uma única plataforma. Este trabalho apresenta o desenvolvimento de um protótipo de modelador de diagramas ER colaborativo, acessível pelo navegador, que permite a múltiplos usuários trabalharem simultaneamente no mesmo diagrama. O sistema foi construído sobre uma arquitetura cliente-servidor, com comunicação bidirecional em tempo real entre os colaboradores e mecanismos para o controle de acessos concorrentes. Adotou-se uma estratégia de persistência que separa o armazenamento de dados estruturados do armazenamento dos diagramas, adequando cada solução à natureza da informação que armazena. O protótipo oferece controle de acesso por perfis de usuário, autenticação segura, gerenciamento de projetos e equipes, e suporte à importação e exportação de definições de banco de dados. A comparação com ferramentas consolidadas no mercado evidenciou que o protótipo preenche uma lacuna ao reunir, de forma gratuita, colaboração em tempo real e interoperabilidade com padrões amplamente utilizados. Os cinco objetivos específicos definidos foram integralmente atendidos, comprovando a viabilidade técnica de uma ferramenta \textit{web} colaborativa para a modelagem de diagramas ER.

\textbf{Palavras-chave}: diagrama entidade-relacionamento; modelagem de banco de dados; colaboração em tempo real; ferramenta \textit{web}; desenvolvimento de \textit{software}.
\end{resumo}

% resumo em inglês
\begin{resumo}[Abstract]
\begin{otherlanguage*}{english}
Database modelling is a fundamental step in software system development, and ER diagrams constitute an essential tool for this purpose. However, available solutions rarely combine real-time collaboration, interactive modelling, and free access in a single platform. This work presents the development of a prototype collaborative ER diagram modeller, accessible through a web browser, that allows multiple users to work simultaneously on the same diagram. The system was built on a client-server architecture, with real-time bidirectional communication between collaborators and mechanisms for concurrent access control. A persistence strategy was adopted that separates the storage of structured data from diagram storage, matching each solution to the nature of the information it stores. The prototype offers role-based access control, secure authentication, project and team management, and support for importing and exporting database definitions. A comparison with established market tools demonstrated that the prototype fills a gap by combining, at no cost, real-time collaboration and interoperability with widely used standards. All five specific objectives defined at the outset were met, proving the technical feasibility of a web-based collaborative tool for ER diagram modelling.

\textbf{Keywords}: entity-relationship diagram; database modelling; real-time collaboration; web tool; software development.
 \end{otherlanguage*}
\end{resumo}
