\begin{resumo}
 A modelagem de diagramas entidade-relacionamento (ER) é etapa essencial no projeto de bancos de dados, porém as ferramentas disponíveis raramente combinam colaboração em tempo real, modelagem interativa e acesso gratuito em uma única solução. Este trabalho apresenta o desenvolvimento de um protótipo de modelador de diagramas ER colaborativo, acessível via navegador \textit{web}, que permite a múltiplos usuários trabalharem simultaneamente no mesmo diagrama. O sistema foi construído sobre uma arquitetura cliente-servidor, adotando Java com Spring Boot no \textit{back-end} e Angular no \textit{front-end}. A comunicação em tempo real entre os colaboradores foi viabilizada pelo protocolo WebSocket em conjunto com o protocolo de mensageria STOMP, enquanto um mecanismo de \textit{locks} em memória com \textit{timeout} automático foi implementado para o controle de concorrência. Para a persistência de dados, adotou-se uma estratégia poliglota: o PostgreSQL armazena informações estruturadas de usuários, projetos e permissões, ao passo que o MongoDB armazena os diagramas como documentos, adequando-se à natureza hierárquica e dinâmica dessa informação. A interface gráfica utiliza a biblioteca GoJS para a renderização e manipulação interativa dos diagramas. O protótipo contempla controle de acesso baseado em três perfis --- \textit{Viewer}, \textit{Editor} e \textit{Owner} ---, autenticação por \textit{tokens} JWT, gerenciamento de projetos e times, e operações de importação e exportação de \textit{scripts} SQL no dialeto MySQL. A comparação com ferramentas consolidadas no mercado --- brModeloWeb, SqlDBM e Vertabelo --- evidenciou que o protótipo preenche uma lacuna ao reunir, de forma gratuita, colaboração em tempo real e interoperabilidade via SQL. Os cinco objetivos específicos definidos foram atendidos, comprovando a viabilidade técnica de uma ferramenta \textit{web} colaborativa para a modelagem de diagramas ER.

 \textbf{Palavras-chave}: diagrama entidade-relacionamento; modelagem de banco de dados; colaboração em tempo real; WebSocket; Spring Boot; Angular.
\end{resumo}

% resumo em inglês
\begin{resumo}[Abstract]
 \begin{otherlanguage*}{english}
  Entity-relationship (ER) diagram modelling is an essential step in database design, yet available tools rarely combine real-time collaboration, interactive modelling, and free access in a single solution. This work presents the development of a prototype collaborative ER diagram modeller, accessible through a web browser, that allows multiple users to work simultaneously on the same diagram. The system was built on a client-server architecture using Java with Spring Boot on the back end and Angular on the front end. Real-time communication between collaborators was enabled by the WebSocket protocol with the STOMP messaging protocol, while an in-memory locking mechanism with automatic timeout was implemented for concurrency control. A polyglot persistence strategy was adopted: PostgreSQL stores structured data for users, projects and permissions, while MongoDB stores diagrams as documents, suited to the hierarchical and dynamic nature of that information. The graphical interface uses the GoJS library for interactive diagram rendering and manipulation. The prototype includes role-based access control with three profiles --- Viewer, Editor and Owner ---, JWT-based authentication, project and team management, and SQL script import and export operations in the MySQL dialect. A comparison with established market tools --- brModeloWeb, SqlDBM and Vertabelo --- demonstrated that the prototype fills a gap by combining, at no cost, real-time collaboration and SQL interoperability. All five specific objectives defined at the outset were met, proving the technical feasibility of a web-based collaborative tool for ER diagram modelling.

  \textbf{Keywords}: entity-relationship diagram; database modelling; real-time collaboration; WebSocket; Spring Boot; Angular.
 \end{otherlanguage*}
\end{resumo}
